Try the components

Interactive examples of Couch’s web controls, using sample data. Try a command, change the power state or choose an input. Everything stays in this page; no device is connected. Layout on the remote may differ.

Command group

command_group

Buttons for the commands your integration declares.

Volume

View declaration
{
  "kind": "command_group",
  "title": "Volume",
  "commands": [
    "volume-up",
    "volume-down"
  ]
}

Status text

status_text

A read-only value. Try the volume buttons to see it change.

View declaration
{
  "kind": "status_text",
  "label": "Volume",
  "field": "volume"
}

Toggle

toggle

A button that sends the command for the opposite state.

Power

View declaration
{
  "kind": "toggle",
  "label": "Power",
  "state": "on",
  "on": "power-on",
  "off": "power-off"
}
